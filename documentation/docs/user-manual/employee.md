# Panduan Pegawai

Pegawai memakai SIMDP untuk melihat profil dan mengelola dokumen miliknya sendiri.

## Yang bisa dilakukan Pegawai

- Login memakai email, NIP, atau NIK.
- Melihat dashboard pribadi.
- Melihat profil sendiri.
- Mengubah data profil yang diizinkan.
- Mengunggah dokumen.
- Mengganti dokumen yang ditolak/kedaluwarsa.
- Melihat status verifikasi dokumen.
- Menghapus dokumen sendiri jika status dan aturan mengizinkan.
- Mengganti password.
- Mengelola sesi akun sendiri.

## Upload dokumen

Alur:

1. Buka halaman Dokumen Saya.
2. Pilih jenis dokumen.
3. Isi metadata yang diminta.
4. Upload file PDF/PNG/JPEG sesuai aturan jenis dokumen.
5. Tunggu verifikasi Staff/Admin.

## Status dokumen

| Status | Arti |
|---|---|
| `PENDING` | Dokumen menunggu verifikasi. |
| `APPROVED` | Dokumen diterima. |
| `REJECTED` | Dokumen ditolak dan perlu diperbaiki. |
| `EXPIRED` | Dokumen sudah melewati tanggal berlaku. |
| `REPLACED` | Dokumen lama sudah diganti oleh upload baru. |

## Tips

- Pastikan file jelas dan tidak rusak.
- Isi tanggal terbit/masa berlaku sesuai isi dokumen.
- Baca catatan reject sebelum upload ulang.
- Jangan membagikan password.
