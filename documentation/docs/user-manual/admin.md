# Panduan Admin

Admin adalah role tertinggi di SIMDP.

## Tanggung jawab Admin

- Mengelola data pegawai.
- Mengelola akun user dan role.
- Mengelola master data kepegawaian.
- Mengelola jenis dokumen.
- Melihat statistik dan compliance.
- Melihat Security Log.
- Mengubah System Setting.
- Menjalankan aksi arsip, restore, dan hapus permanen sesuai aturan.

## Menu penting

| Menu | Fungsi |
|---|---|
| Dashboard | Ringkasan statistik. |
| Master Data Pegawai | CRUD pegawai, arsip, restore, export/import. |
| Master Data Dokumen | Kelola jenis dokumen dan target rules. |
| Verifikasi | Cek dan approve/reject dokumen. |
| Statistik | Analisis dokumen/pegawai. |
| Security Log | Audit trail aksi sensitif. |
| System Settings | Konfigurasi sistem seperti upload limit dan reminder. |

## Aksi sensitif

Beberapa aksi membutuhkan konfirmasi kritis:

- arsip pegawai;
- pulihkan pegawai;
- hapus permanen;
- ubah role/status akun;
- ubah system setting penting.

## Catatan keamanan

- Jangan membagikan akun Admin.
- Gunakan password kuat.
- Cek Security Log jika ada aktivitas mencurigakan.
- Export CSV/PDF berisi data sensitif dan harus disimpan dengan hati-hati.
